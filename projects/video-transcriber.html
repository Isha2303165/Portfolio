AI-Powered Video Transcriber

A privacy-focused desktop application that converts video content into accurate transcripts and subtitles. The application uses FFmpeg for media processing, Faster-Whisper for automatic speech recognition, and a custom T5 natural-language-processing model trained on more than 100,000 sentence pairs to improve transcript quality.

Python Faster-Whisper FFmpeg T5 NLP ASR Tkinter Local Inference

How It Works

  1. The user selects and uploads a video from the desktop application.
  2. FFmpeg extracts and prepares the audio track for speech recognition.
  3. Faster-Whisper converts the audio into timestamped text.
  4. The custom T5 model cleans and improves the generated transcript.
  5. The final transcript and subtitle output are generated for the user.
